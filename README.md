# HANZ Design Collective 网站

https://hanzdesigncollective.com ，由 GitHub Pages 发布。推送到 `main` 后大约 1 分钟网站自动更新。

| 文件 | 内容 |
|---|---|
| `index.html` | 所有文字和页面结构（英文在 `lang-en`，中文在 `lang-zh`） |
| `assets/css/style.css` | 样式、颜色、字体 |
| `assets/js/site.js` | 中英文切换、深浅色切换 |
| `assets/images/` | 图片 |
| `assets/fonts/` | 字体文件 |
| `CNAME` | 域名设置，不要删除 |

## 改网站

1. 在 Claude Code 里打开这个文件夹，告诉 Claude 要改什么
2. 让 Claude 先在本地预览，确认后提交并推送

每次改动都有记录，在 GitHub 上可以找回任何旧版本。
